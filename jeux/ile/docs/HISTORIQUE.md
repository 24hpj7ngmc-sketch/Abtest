## Le lobby (V4.1) — l'Île céleste, à bâtir et à sculpter
Frédéric a refusé le premier lobby (V4.0, parvis de marbre figé avec les héros en cercle : « j'aime bien mais non »). Ce qu'il veut : une île céleste où chacun
bâtit son petit village (pas de défense, pas d'attaque) et sculpte son relief.
- `lobby.js` (repère /*@LOBBY@*/ dans tpl.html, juste avant la boucle) : scène three.js à part (`lob`, caméra `lcam`), ciel étoilé, mer de nuages, îlots.

  Sommets verrouillés : le bord, le parvis des portails (`TFIX`), et sous les bâtiments (`terrLocks`). L'eau apparaît sous -0,75 m.

## Fabrication (nouveau depuis la V3.0)
- `tpl.html` = la page (HTML, CSS, règles du jeu entre //<SIM> et //</SIM>, HUD, boucle). Deux repères : /*@GFX@*/ et /*@SCENE@*/.
- `sound.js` (repère /*@SOUND@*/) = bruitages fabriqués par Web Audio (SND.play / SND.at), `feel(ev)` (son + viseur + ralenti par événement), `feelTick`.
- `scene.js` = TOUT l'affichage 3D (sol, décor, défenses, ennemis, effets, mains) + worldTick / viewsTick / handsTick / skyTick appelés par la boucle.
- `gfx/kit.js` (K) + `gfx/models/*.js` (SH, MODELS) = modèles. `gfx/models/defaults.js` = modèles de secours simples.
- `lobby.js` = l'Île céleste (voir plus haut).
- `python3 build.py` → `ile-des-cinq.html` (+ all.js pour node --check). `./mktest.sh` = build + test3d.html (rendu three-lite) + test.html (sans dessin).
- Tests : `node run1.js` (démarrage), `node run2.js` (toute l'interface, 5 héros × 2 modes, ~5 min), `node run9.js` (tutoriel), `node run10.js` (boutique).

- three-lite (gfx/three-lite.js) : moteur d'aperçu maison. Corrigé le 13/11 : setPixelRatio ne doit pas redimensionner le canvas (sinon l'image est étirée).
